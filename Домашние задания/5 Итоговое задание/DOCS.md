# RPG Game

Простая RPG игра с различными классами персонажей и оружия.

## Структура проекта

```
src/
  ├── weapons/          # Классы оружия
  │   ├── Weapon.js     # Базовый класс оружия
  │   ├── BasicWeapons.js    # Базовые типы оружия
  │   └── ImprovedWeapons.js # Улучшенные типы оружия
  ├── players/          # Классы персонажей
  │   ├── Player.js     # Базовый класс игрока
  │   ├── BasicPlayers.js    # Базовые классы персонажей
  │   └── ImprovedPlayers.js # Улучшенные классы персонажей
  ├── utils/            # Утилиты
  │   └── random.js     # Генератор случайных чисел
  ├── game.js           # Основная игровая логика
  ├── console.js        # Запуск игры в консоли
  └── index.html        # Веб-интерфейс игры
tests/                  # Тесты
  ├── weapons/          # Тесты оружия
  └── players/          # Тесты персонажей
```

## Установка

```bash
yarn install
```

## Запуск игры

### В консоли

```bash
node src/console.js
```

Игра будет запущена в консольном режиме с выводом всех действий в терминал.

### В браузере

```bash
npx http-server src -o
```

Откроется веб-интерфейс игры с визуальным отображением поля боя и состояния игроков.
Все действия также будут логироваться в консоль браузера.

## Линтинг и форматирование

В проекте используются ESLint и Prettier для обеспечения единого стиля кода.

### Проверка кода линтером


```bash

```

### Форматирование кода

```bash

```

### Проверка форматирования

```bash

```

## Пример использования

```javascript
import { Warrior, Archer, Mage } from './players/BasicPlayers.js';
import { play } from './game.js';

const warrior = new Warrior(0, 'Артур');
const archer = new Archer(5, 'Робин');
const mage = new Mage(10, 'Мерлин');

const players = [warrior, archer, mage];
const winner = play(players);
```

## Особенности

### Оружие

- Базовые типы: Меч, Лук, Посох, Нож, Рука
- Улучшенные типы: Длинный лук, Секира, Посох Бури

### Персонажи

- Базовые классы: Воин, Лучник, Маг
- Улучшенные классы: Гном, Арбалетчик, Демиург

Каждый класс имеет свои уникальные характеристики и способности.

### Логирование

Все действия игры логируются в консоль:
- Начало игры и список участников
- Каждый ход с детальной информацией:
  - Текущее состояние игрока (здоровье, позиция, оружие)
  - Перемещения
  - Атаки и нанесенный урон
  - Смена оружия
  - Состояние всех игроков после хода
- Окончание игры и победитель

При запуске в браузере та же информация дополнительно отображается в веб-интерфейсе.

## Правила оформления кода

Проект следует строгим правилам оформления кода, которые автоматически проверяются с помощью ESLint и Prettier:

- Отступы: 2 пробела
- Кавычки: одинарные
- Точка с запятой: обязательна
- Максимальная длина строки: 100 символов
- Стиль фигурных скобок: 1tbs
- Пробелы вокруг операторов: обязательны
- Вертикальные отступы между блоками: одна пустая строка
- Именование:
  - Переменные: camelCase
  - Функции: camelCase
  - Классы: PascalCase
- Комментарии:
  - Однострочные: // с пробелом
  - Многострочные: /* с пробелом и */ на новой строке
